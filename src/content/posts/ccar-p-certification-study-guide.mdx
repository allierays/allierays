AI can write the code now, but the architecture decisions are still yours. They're what turn a vibe-coded demo into a production-ready system that's secure, scalable, and observable. Should it be a workflow or an agent? How much autonomy should the agent get? Which tools does it actually need? The [Claude Certified Architect - Professional](https://anthropic-partners.skilljar.com/claude-certified-architect-professional-certification) certification tests how you think through decisions like these.

I helped my friend Eddie Belaval and [id8Labs](https://id8labs.app/) put together a cohort that grew to 74 people to prep for the exam. There's no official mock exam, so I used Claude to build one for the group. After I passed, I reviewed the questions and tweaked the format. I'm sharing it below in case it helps you too.
